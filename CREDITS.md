# Credits

The `teach` skill is an independent adaptation inspired by the teaching patterns in Geoffrey Litt’s original explain-diff HTML skill:

- Geoffrey Litt, [explain-diff HTML skill](https://gist.github.com/geoffreylitt/a29df1b5f9865506e8952488eac3d524)

The inspiration includes starting with background and intuition, using interactive figures, and ending with a comprehension quiz. This repository does not claim authorship of the original explain-diff skill and does not reproduce its implementation.
